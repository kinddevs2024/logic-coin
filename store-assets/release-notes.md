# Logic Coin 1.0.0 — release notes

## O‘zbekcha

Logic Coin’ning birinchi versiyasi: jamg‘arma maqsadi, vazifalar, kunlik bonuslar, faollik taqvimi, do‘stlarni taklif qilish va uchta o‘yin. Email, Google, Yandex va Telegram orqali kirish qo‘llab-quvvatlanadi.

## Русский

Первая версия Logic Coin: цель накопления, задания, ежедневные бонусы, календарь активности, приглашение друзей и три встроенные игры. Поддерживается вход через email, Google, Яндекс и Telegram.

## English

The first Logic Coin release includes a savings goal, tasks, daily bonuses, activity calendar, friend invitations, and three built-in games. Sign-in is available through email, Google, Yandex, and Telegram.
