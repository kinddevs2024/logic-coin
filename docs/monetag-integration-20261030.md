## Behavior

- Monetag is initialized only in Telegram Mini App context. Ordinary website visits and native APK ad providers retain their existing behavior.
- Rewarded Interstitial replaces the unavailable web reward provider for existing gift/fortune buttons. Every show carries its server session UUID as ymid and its placement as requestVar.
- Reward requires both a client result marked valued and an authenticated valued Monetag server postback. An atomic readiness transition accepts either delivery order. Unvalued, invalid-zone, expired, unknown and duplicate callbacks do not create another reward. Existing server claim/idempotency rules remain in force.
- After-game interstitials use existing game completion points, capped at two per six minutes and at least 30 seconds apart. The user selected buttons and after-game placement: no autoplay, no app-open ads, no popup fallback.
- Callback URL was saved in the Monetag account after explicit user confirmation and verified by reloading the settings page. Secret exists only in backend environment and the private SSP URL; no secret is included here or in browser bundles.
