Deep navy background, electric blue/cyan accents, glossy 3D game tiles and small gold coins on the right; logo and bold clean Cyrillic typography on the left. Exact text: 'Logic Coin', 'Играй. Соревнуйся. Выигрывай.', and smaller 'Игры → Челленджи → Денежные призы'. Small footer 'logic-coin.online'. Premium, simple, uncluttered composition. No guaranteed earning amounts, no financial promises, no QR code, no fake phone UI. Keep all text well inside safe margins. This is a final promotional raster image for production, not a UI mockup.

## Profile background prompt

Create a production raster background for a Logic Coin public profile social preview, landscape ratio 1.91:1. Deep midnight navy, subtle polished electric-blue and cyan lighting confined to the outer edges, very restrained premium game platform styling. Main center and left areas must be almost uniform dark navy, empty and high-contrast so white profile text can be composed by software. No text, no letters, no numbers, no logos, no portraits, no QR, no UI cards, no frames. Beautiful subtle blue glow in the far top-right and bottom-right only. This is a background asset, not a finished mockup.

## Limitations

Messaging apps choose whether to show a preview and may cache older images. A URL with Open Graph metadata is not a forced file attachment. Installed APKs require a new application build to display the new in-app QR; server-side link previews also work with links sent from the existing APK.
