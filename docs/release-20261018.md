## Remaining verification and limitations

- The phone is currently unavailable through ADB and wireless discovery. The final close-button alignment and latest green interface have **not** been visually checked on the physical phone.
- Real gift and rewarded-ad flows have not received final device verification. No fabricated reward callbacks or manual coin credits were used as substitutes.
- System push delivery is still blocked by missing owned Firebase/Expo configuration. Existing registered Android devices had no usable push tokens. Publishing this OTA does not resolve that configuration gap.
- Browser automation timed out before a visual check; HTTP and signed-artifact checks do not establish browser visual QA.
- Semantic artwork, country flags and third-party service identity colours were preserved; the green pass changes application surfaces and controls.
