# Hangman availability and APK 12

The new Android binary is version 1.3.6, versionCode 12. Hangman is visible in the catalog only when expo-application reports an installed Android build >=12. The website and existing APKs <=11 hide the game after OTA. The binary's version is used instead of OTA manifest version so updates cannot unlock it on old binaries. Practice deep links are also gated.

The current published daily challenge on 2026-10-29 already contained Hangman and had 121 attempts when visibility was changed. Its game IDs, attempts and rewards were preserved, and participants can finish it. Hangman is excluded from future random challenge sets (`challengeEnabled=false`) while remaining enabled for practice in the new APK. This is a deliberate exception to immediate hiding so existing participants are not stranded.

Server release: `/srv/apps/logic-coin/diagnostics/hangman-hide-20261029`. Rollback: `/srv/apps/logic-coin/backups/hangman-hide-20261029`, plus `game-before-hiding.json` for the previous catalog flag. Website and all 11 existing signed Android OTA configurations were published; 172 unique asset URLs and signatures passed verification. Frontend typecheck, lint and 119 Vitest tests passed on the server; Node smoke/linking tests also passed. A scoped compatibility test verifies old Android build codes, code 12 and web visibility.

GitHub workflow android-apk.yml checks the frontend, exports Android JavaScript, generates native sources, builds APK/AAB and signs both. The APK contains Hangman code, assets, fonts, sounds, translations, gifts and scoring. No APK download link is replaced automatically by dispatching this workflow.
